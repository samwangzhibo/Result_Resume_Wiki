## 批量压缩工程图片（PNG/JPEG）保证清晰度

**王总要求**：压缩工程下所有图片，但保证原始文章仍然清晰可看。

### 工作流程
1. **环境准备**：Pillow 12.3.0（用清华源安装在 managed venv）
2. **分析图片**：120 张位图（117 PNG + 3 JPEG），共 107.45 MB
   - 最长边分布：4 张 ≥4096px（最大 7658px）、50 张 2048-4095、46 张 1024-2047、20 张 <1024
   - 模式：59 RGB、51 RGBA、10 调色板
3. **备份原图**：`WorkBuddyRaw/临时/图片压缩备份/2026-08-10/`，保持相对目录结构
4. **压缩策略**（保证视觉无损）：
   - PNG：optimize=True；RGBA 全不透明 → 转 RGB
   - JPEG：quality=85, optimize, progressive
   - **关键**：最长边 > 3000px 的超大图等比缩到 3000px（Lanczos），文章里显示宽度最多 1200px，3000px 仍保持 2.5x 超采样，清晰度无损失
   - 不转格式（截图/图表转 JPEG 会糊字）
5. **原子替换**：写临时文件 → PIL 校验尺寸 → os.replace
6. **结果校验**：verify + load 全部 120 张通过（0 损坏）
